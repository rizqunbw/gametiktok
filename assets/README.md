# Asset workspace

This repository currently contains **documentation only**, not downloadable 3D binaries.

- `source/`: place official downloaded ZIPs locally; do not commit by default.
- `optimized/`: runtime glTF/GLB after license review and performance optimization.
- `licenses/`: keep source URLs, original license copies and attribution when needed.
- `vfx/`: original particle/VFX assets.

See [../ASSET_LIST.md](../ASSET_LIST.md) for official sources and acquisition checklist.
